## 이전 13장면 콘티의 장면과 내레이션

아래 표는 이전 콘티의 것이며, 현재 영상의 장면과 내레이션은 이와 다릅니다.

| 순서 | 장면 | 내레이션 |
| --- | --- | --- |
| 1 | 제목 | 호출부터 귀가까지 챙기는 대리 에이전트, 코-대리입니다. |
| 2 | 대리 부르기 | 어디서 부르든, 코-대리가 호출을 받아 기사님을 배정하고 예약을 차량에 연결합니다. |
| 3 | 타면 예약이 나타남 | 시동을 걸면 예약이 차량 화면에 나타납니다. 배정된 기사님과 목적지, 요금을 차 안에서 다시 설명할 필요가 없습니다. |
| 4 | 출발 | 기어를 드라이브에 넣으면 운행 기록이 시작됩니다. |
| 5 | 운행 중 | 예약만으로는 알 수 없는 출발과 정차, 하차를 차가 알려 줍니다. 코-대리는 이 신호로 운행을 지켜봅니다. |
| 6 | 집 주차 안내 | 집 근처에 오면 차주가 적어 둔 주차 방법을 기사님께 안내합니다. |
| 7 | 차단기 앞 정차 | 차단기 앞에서 잠깐 서도 운행은 이어집니다. |
| 8 | 주차 | 주차하면 기사님이 세운 자리를 기록에 남깁니다. |
| 9 | 운행 종료와 결제 | 운전석이 비면 차가 알리고, 코-대리가 종료를 확정합니다. 요금은 자동으로 결제됩니다. |
| 10 | 차주에게 결과 전달 | 결제 내역과 주차 위치를 차주에게 보냅니다. 문이 잠긴 것까지 확인합니다. |
| 11 | 문제가 생기면 | 문제가 생기면 코-대리가 조치하고 차주에게 알립니다. |
| 12 | 다음 날 아침 | 다음 날 아침, 어젯밤 귀가 기록이 차에 남아 있습니다. |
| 13 | 맺음 | 대리 호출부터 귀가까지, 코-대리가 챙깁니다. |

## 이전 콘티에 대해 알아 둘 것

- 차 화면과 휴대폰 페이지는 에뮬레이터와 시연용 서버의 실제 화면을 찍은 것입니다. 화면 속 기사님 이름, 번호, 요금은 예시입니다.
- 대화 화면은 그림입니다.
- 결제는 시연용 표시이며 실제 결제는 일어나지 않습니다.
- 내레이션은 합성 음성입니다.
