# 유사 기능 조사 (2026-11-10)

기획 초기에 "대리 모드"라는 이름으로 조사한 기록입니다. 앱 이름은 그 뒤 코-대리로 바뀌었습니다.

## 결론
"대리기사가 내 차를 몰고 차주이 함께 타고 가는 상황"을 위한 차량 기능은 찾지 못함. 가장 가까운 것은 발레 모드(차주 없이 차를 맡길 때 화면을 잠그는 기능)이며, 목적이 다름. 다만 조사한 페이지 범위 안에서의 결과이고, 대리 앱의 최신 기능 전체를 확인한 것은 아님.

## 1. 차량 순정 기능
| 기능 | 하는 일 | 대리 모드와 겹침 |
|---|---|---|
| Pleos 발레 모드 | 비밀번호로 화면·버튼 조작 제한(개인정보 보호). 세차·유틸리티·스테이·루틴 모드와 동시 실행 불가. 5회 오류 시 마이현대로 해제 | 개인정보 가리기만 겹침. 운행 기록·알림·안내 없음 |
| 테슬라 Valet Mode (2015~) | 속도 제한(기본 70mph), 가속 제한, 글로브박스·프렁크 잠금, 주소·연락처·일정·내비 기록 숨김, 음성·블루투스 차단, 프로필 사용 불가 | 개인정보 + 속도 제한. 안내는 오히려 차단, 운행 리포트 없음 |
| 현대 승하차 편의 | 시동 끄고 문 열면 시트 뒤로, 닫으면 원위치 | 운전자가 바뀐 것과 무관 |
| 현대 시트 메모리 | 위치 1·2 버튼을 눌러야 복원(수동) | 자동 복원 아님 → 우리 앱이 채울 틈 |
| Pleos 프로필 | 블루링크 계정·디지털 키·비밀번호. 시트 위치 저장 여부는 매뉴얼에 명시 없음 | 확인 필요 |
| 중국 "AI 代驾" | 경로를 기억해 주행 보조하는 기능(샤오펑 등). 사람 대리기사와 무관 | 겹치지 않음 |

## 2. 대리 플랫폼 (휴대폰 앱)
- 카카오T 대리: 목적지·경유지, 요금 제안, 기사 배차·도착 추적. 소개 페이지엔 차량 연동 언급 없음.
- 티맵 안심대리(2021): 티맵 안에서 호출, 기사 운전점수(급가속·급감속·과속), 보험. 실시간 위치 공유·별점은 당시 계획.
- 대구로 대리운전(2024, 공공앱): 기사 실시간 위치, 안심메시지(가족에게 운행 정보 문자), 차량 정보 1회 등록.
- 마이현대 대리운전: 카라이프 메뉴에 호출이 있다는 것만 확인, 상세 미확인.
- KT 커넥티드카 + 카카오T(2019): MoU 단계, 출시 확인 안 됨.
- 정리: 휴대폰 앱은 호출·요금·기사 위치·가족 문자까지 함. 차 안 데이터(시트·착석·문·기어·조명)를 쓰는 대리 앱은 못 찾음.

## 4. 겹치는 부분과 비어 있는 부분
| 대리 모드 기능 | 이미 있는 것 | 판정 |
|---|---|---|
| 개인정보 가리기 | 발레 모드 | 순정에 맡김. 우리 핵심 아님 |
| 차주에게 운행 리포트(거리·시간·급조작) | 티맵 기사 점수(휴대폰 기준, 플랫폼 내부용) | 차량 신호 기준으로는 없음 |
| 시트 자동 복원 | 수동 메모리 버튼 | 비어 있음 |
| 차주 좌석 편의 자동화 | 없음 | 비어 있음 |
| 기사에게 집 주차 위치 음성 안내 | 없음(테슬라는 오히려 차단) | 비어 있음 |
| 가족 도착 알림 | 대구로 안심메시지(출발 시 문자), 마이현대 위치 공유 | 일부 겹침. 차가 "주차 완료·문 잠김"을 확인해 보내는 것은 없음 |

## 정정 (2026-11-10 19:10)

위 표의 발레 모드 설명은 불완전했다. 현대차그룹 공식 글(https://www.hyundaimotorgroup.com/ko/amp/CONT0000000000050086)에 따르면 이전 세대 인포테인먼트의 발레 모드는 "발레 파킹이나 대리를 맡긴 이후부터" 주행 시간·거리·최고 속도를 기록하고 휴대폰 앱으로 위치와 경로를 보여 준다. 따라서 운행 기록은 순정과 겹친다. Pleos 매뉴얼에는 조작 제한만 나오며 기록 기능의 유무는 확인하지 못했다. "발레 모드와 동시에 못 쓴다"는 서술도 매뉴얼 근거가 없는 추론이었다. 차별점은 차주가 함께 타는 귀가 흐름이다.
