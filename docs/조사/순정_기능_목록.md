# Pleos Connect·현대차 순정 기능 목록 (2026-11-10 조사)
근거: 현대 오너스매뉴얼 Connect-S(=Pleos Connect, 한국어) 섹션 우선, 보도·앱스토어는 보조. 트림별 적용 여부는 미확인("사양 적용 시").

## 차 안 순정 기능
- Gleo AI: "글레오" 호출, 좌석 구분, 내비·전화·메시지·공조(시트·핸들 열선/통풍)·창문·도어·트렁크·앰비언트 조명·설정·음악·차량 정보·일반 정보. 다정/정중 말투 선택. (003_Corefeatures_1)
- 순정 내비: EV 충전 경유 경로, 주변 장소 거리순 검색(10월 OTA).
- 주행 모드: ECO/NORMAL/SPORT/MY, 지형 모드.
- 안전: 운전자 주의 경고(앞차 출발 알림, 부주의 운전 경고 → 휴식 권유, 전방 주시 경고), 차로 이탈 방지, 후측방 모니터, 충돌방지 보조, 안전 하차 경고, 페달 오조작 안전 보조, 제한속도 보조, SCC/NSCC, 주차 거리 경고, 실내 카메라 안전벨트 경고, 뒷좌석 승객 알림. (009_Vehiclesettings_3, _15)
- 모드: 세차 모드(미러 접기·창문/선루프 닫기·오토 와이퍼 끄기·히든 핸들·트렁크 외부 열림 막기·내기 순환, 006_Drivingmodes_4), 스테이 모드(시동 끈 채 기기 사용, 도착 후 예약 가능), 발레 모드, 중립 주차, 루틴 모드(발레 모드 설명에 언급, 상세 미확인).
- 펫 모드: Pleos Connect 한국 매뉴얼에선 못 찾음. 유럽 ccNC_Lite와 기아 PBV에는 있음 → 언제든 들어올 수 있음.
- 시트: 승하차 편의, 스마트 자세 제어, 주행 중 자세 보조. 릴렉스·마사지·스트레스 모드 없음.
- 프로필: 프로필별 블루링크 계정, 디지털 키 공유.
- 10월 OTA(그랜저·아반떼·투싼): 주행 화면 문 잠금 버튼, 기어 표시, RPM 위젯, 음성 메시지 TTS, 뒷좌석 전화·메시지 음성 명령 제한.
- 주행 중 유튜브·게임 차단, 비상등·와이퍼 음성 제어 불가.

## 블루링크·마이현대 앱
- 원격: 공조·도어·창문·주차 위치·목적지 전송·차량 상태·음성. 시동 끈 뒤 336시간.
- 안전: 에어백 전개 자동 통보, SOS, 도난 추적·알림, 뒷좌석 승객 알림, 발레 모드.
- 관리: 차량 진단, OTA, 안전운전 습관, 원격 진단, 소모품·엔진오일 알림, 정비 예약, 차계부(차량 기록), 빌트인캠 영상.
- Driving insight: 안전운전 점수(최근 90일, 급가속·급제동·심야 주행) + 보험 할인 연계, 운전 습관 기록.
- 가족: 위치·목적지·남은 거리 공유(지도 주변찾기), 카셰어(원격 제어·디지털 키 공유).
- 카라이프: 대리운전, 손세차·방문 세차 예약, 주정차 단속 알림, 현대페이, EV 충전.
