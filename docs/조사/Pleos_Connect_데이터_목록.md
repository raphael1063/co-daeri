## 3. 위치 (FusedLocation)
- 위도·경도·고도·방향·정확도·시각, 연속 갱신.
- 지오펜스: 특정 장소 반경 진입·이탈 알림.

## 4. 음성 (TTS / STT)
- TTS: 한국어(ko-KR)·영어·프랑스어·스페인어 음성 합성. 서버·온디바이스·하이브리드.
- STT: 말을 텍스트로 변환(명령 실행은 앱이 직접). 지원 언어 목록은 미확인.

## 5. Gleo AI 연동 (문서상 구조만 확인, 공모전 사용 가능 여부 미확인)
- 앱이 함수 목록(App Schema JSON)을 등록 → 사용자가 Gleo에게 말하면 Gleo가 우리 앱 함수를 호출 → 앱이 결과를 돌려줌.

## 6. 플랫폼 상태
- 주행 중/정차 중 제한 상태 (CarUxRestrictions): 지금 영상·키보드·복잡한 화면이 허용되는지.
- 일반 안드로이드: 시각, 네트워크(서버 연동), 앱 자체 저장소.

## 7. 조합하면 얻을 수 있는 파생 데이터 (예시)
- 대략적 속도: 트립 거리 변화 ÷ 시간
- 탑승 인원·좌석 배치: 착석 + 벨트
- 운전 상황: 기어 + 브레이크 + 조향 + 방향지시등 + 다음 회전 안내까지 거리
- 날씨 추정: 와이퍼 + 안개등 + 성에 제거 + 외기 온도(확인 필요)
- 출발·도착·정차 시간: 기어 P↔D, 문 열림, 도착 이벤트
