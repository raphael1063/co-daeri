## 읽는 순서

1. [기획서](기획서.md)로 무엇을 왜 만들었는지 봅니다.
2. [시연 영상](영상/코-대리_시연영상.mp4)으로 한 번의 대리 이용이 어떻게 흘러가는지 봅니다.
3. 저장소 README의 "심사위원용 빠른 시작"대로 에뮬레이터와 심사용 콘솔에서 직접 눌러 봅니다.
4. [에뮬레이터 확인 기록](검증/README.md)에서 확인된 것과 확인하지 못한 것을 봅니다.

## 알아 둘 것

- 현재 소스는 0.8.54이며, 동봉 APK의 실제 버전은 0.4.5(`com.lrlr.dondaeri`)입니다. 최신 기능은 저장소 README의 소스 빌드 방법으로 확인합니다. 영상·개별 화면도 제작 당시의 기록이므로 최신 동작은 기획서와 코드 대조를 함께 봅니다.

- 예약, 기사님, 결제는 모두 시연용 서버가 만든 가상의 것입니다. 화면 속 이름, 번호, 요금은 예시입니다.
- 시연 영상의 대화 화면은 그림입니다. 차 화면과 휴대폰 페이지는 에뮬레이터와 시연용 서버의 실제 화면입니다.
- 조사 자료는 기획 초기(2026년 11월 10일 전후)에 공식 문서와 SDK를 읽고 정리한 것입니다. 그 뒤 에뮬레이터에서 확인해 달라진 내용은 확인 기록과 기획서가 우선합니다.
